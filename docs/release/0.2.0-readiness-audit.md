# Edades del Perú 0.2.0 — release readiness audit

**Status:** snapshot · **Audited:** 2026-11-19 · **Base commit:** `d548957` (`main`) ·
**Release branch:** `release/0.2.0-closeout`

This is the audit behind the 0.2.0 release. It records what was checked, what failed, what is still
unverified, and the minimum work that remains. It is not a redesign proposal: the game is content-complete
for the campaign-only release, and the closeout is validation, packaging and documentation.

The 0.1.0 snapshot is [`../design/release-candidate.md`](../design/release-candidate.md); it is archived and
describes the October build, not this one.

## 1. Executive summary

The codebase is healthier than its release process.

- **No release-blocking code defect was found.** `yarn verify:fast` is green (987 tests), CI and the fast
  E2E suite are green on `main`, the 20-mission layout/victory audit reports 0 issues, and the seven
  newest missions now have a real-command, no-cheat full path (`tests/e2e/release-playtest.spec.ts`).
- **The public artifact does not match the repository.** GitHub Pages serves a build from
  `2026-11-18 13:34` (`b657f4b`, PR #535), **56 commits behind** `main` and **without 7 of the 20
  missions**. The public menu still shows the old catalogue.
- **`v0.1.0` already exists** (2026-10-19, 9 missions). 0.2.0 is the honest version for this build; rewriting
  a published tag is not recommended.
- **Seven missions still need a human no-cheat playtest.** Their Play gate is `P` by the project's own
  quality bar; the new automated path is strong evidence, not a substitute for a person playing them.
- **The distributed build now ships `LICENSE` and `ATTRIBUTION.md`**, and the main menu has a **Créditos**
  panel with the Caral CC BY 4.0 attribution. The Cloudflare Workers AI terms remain a legal confirmation
  for commercial distribution; this release is free.
- **The docs now agree with the code** for the points that mattered: version, m8 bench status, B15–B17,
  the 20-mission catalogue, the reused kits and the known limitations.

**Recommendation: publish 0.2.0 with known limitations.** The automated no-cheat path is the release gate
for this build; the seven human passes are the first post-release validation and are declared in the notes.
No new phase, no new mission, no architecture change, no performance or size budget increase.

## 5. Gameplay experience

Verified with E2E: landing → **Entrar** → series intro → main menu → campaigns → briefing → tutorial →
play → victory/defeat → epilogue → next mission; continue from a save; Codex; Options; "Cómo jugar";
post-game stats; replay.

- Briefing and tutorial fit **1280×800 and 1600×900** in all 20 missions; every briefing has art;
  every tutorial is visible (`review/audit/report.json`, `ok:true`, 0 issues).
- HUD panels do not overlap at **1280×720, 1600×900 and 1920×1080** (`tests/e2e/hud-layout.spec.ts`).
- Save/load: 15 dedicated tests plus the 20-mission round-trip; mid-act saves for m5–m9, Tambotoco, Lima,
  Junta and m6b; the seven new missions cover the opening save.
- Victory shows the mission-specific epilogue and the optional summary; the next mission opens from the
  result screen; the last mission returns to the campaign hub.

Open experience issues:

1. **Opening framing.** `m_real_felipe` starts with the camp and the artillery clipped by the bottom edge;
   `m_cusco_1536` starts with the camp in the top-left and the objective ring off the right edge; `m6b`
   and `m8` start with the camp in a corner and the objective off-screen. The tutorial asks the player to
   select units that are at or beyond the edge. Evidence: `review/audit-*-open_0.png` (1600×900, high
   quality, 2026-11-19). P2.
2. **Sparse late missions.** m5, m6b, m7 and m8 read as a small camp in a large field at RTS zoom,
   especially at low quality. This is a composition/density issue, not a functional defect. P2/P3.
3. **Protected commanders are punishing.** Leaving San Martín or Cáceres at the base while the army
   advances loses the mission. The objective is visible, but the human playtest should confirm it is fair.
   P2.
4. **Pacing.** The GDD targets 30–40 minutes; the automated paths finish in 3–8 simulated minutes and the
   human 20–30 minute path is unmeasured. P2.
5. **Legacy progress.** 0.1.0 stored one mission count. The migration now maps it to the old nine-mission
   order across the five campaigns instead of only Preinca (`src/campaign/progress.ts`), but the mapping
   is still approximate. P2.

No stuck objective, unresponsive unit, abandoned AI objective, broken transition or save loss was found in
the executed suites.

## 10. Prioritized list

### P0 — blocks publication

- P0-1. Deploy Pages from the 0.2.0 tag/commit and verify the live site has 20 missions and the 4-per-campaign
  catalogue.
- P0-2. Use **0.2.0** for this build. Keep `v0.1.0` as the October demo.

### P1 — before announcing

- P1-1. Human no-cheat playtest of the seven 2026-11-18 missions. The automated path is green; a person must
  still play each one and record the time and any blocker. If one fails, it becomes P0.
- P1-2. Confirm the Cloudflare Workers AI / image-model terms for the chosen distribution (free vs commercial).
  The build now ships the licence and the CC BY attribution.
- P1-3. Tag, release notes and the Pages/itch builds must be generated from the same commit.

### P2 — after 0.2.0

- Opening framing for `m_real_felipe`, `m_cusco_1536`, `m6b` and `m8`.
- Real-GPU site views for the seven new missions.
- Human art review of the reused kits (#343).
- Pacing measurement (30–40 min target).
- Long-session memory/stability test and a fresh AI matrix.
- Legacy progress mapping refinement.
- B13 late-view optimization for m6b/m8.

### P3 — out of scope

- Art polish beyond RTS readability, dedicated star-fort GLB, unique Ayar outfits, recorded audio.
- Geographic §6.1–6.3 composition work.
- Multiplayer, public skirmish, editor, desktop build, expansion missions.

## 12. Final recommendation

**Publish 0.2.0 with known limitations.** The core game is stable and content-complete; the remaining work
is release execution and human validation, not another development phase. The release notes declare the
seven pending human passes, the reused-kit art review, the iGPU performance band and the absence of a
real-GPU row for the newest missions. If a human pass finds a blocker, ship 0.2.1 rather than reopening the
scope.

- **No real-GPU measurement** was taken in this audit; the frame times are from the 2026-11-17 document.

- **No cross-browser or mobile test**; only Chromium.
- **No full `bench:check` or `bench:site-views` run**; the tight rows were re-measured, the rest are the
  latest local rows.

- **No Pages or itch deployment** was performed as part of the audit.
